# External Source Repository Queue — Builds 69–133

Status: **research inbox only — not audited / not approved for adoption**

This file is the canonical queue of GitHub repositories, organizations, topic pages and specific issues supplied as potential implementation references for future Vortex Ars AI builds.

## Operating rule

Do **not** bulk-audit this queue.

When a build becomes active:

1. read only the repositories mapped to that build;
2. inspect current repository state, language, maintenance activity and license;
3. classify each source as `direct-candidate`, `adapter`, `optional-tool`, `reference-only` or `reject`;
4. record exactly what problem it can help solve;
5. record what must **not** be copied or depended upon;
6. preserve provenance and license notes;
7. implement only through the owning Vortex contract/authority boundary;
8. never make an external project a hidden runtime dependency unless explicitly approved by architecture and license review.

Items in this queue carry **zero architectural authority** until that per-build triage happens.

Obvious duplicate URLs were collapsed. Malformed pasted URLs were normalized only enough to preserve the apparent intended repositories; this is not an audit.

## Per-build triage record template

When a build is activated, create/update a narrow record with:

```text
source:
build:
status: queued | audited
license:
activity:
language:
classification: direct-candidate | adapter | optional-tool | reference-only | reject
useful_for:
do_not_reuse:
security_notes:
architecture_boundary:
provenance:
decision:
```

Do not remove rejected sources from this inbox; record the rejection in the build-specific triage so the same repository is not repeatedly reconsidered without new evidence.
