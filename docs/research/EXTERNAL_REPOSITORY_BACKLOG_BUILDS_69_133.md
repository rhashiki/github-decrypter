# External Source Repository Backlog — Builds 69–133

Status: **INTAKE ONLY — UNREVIEWED**

Purpose: preserve user-supplied GitHub repositories that may accelerate future Vortex Ars AI Builds without forcing bulk research, premature adoption or trial-and-error reinvention.

## Mandatory usage rule

This file is a **just-in-time research backlog**, not an approved dependency list.

Before implementing an owning Build from 69 onward:

1. Read **only** the candidate block for the current Build (plus an adjacent Build only when the architecture directly overlaps).
2. Audit each candidate for purpose, current activity, license, language/stack, architecture fit, security/supply-chain risk, reusable mechanisms and integration cost.
3. Classify each candidate as one of:
   - `ADOPT` — direct reusable dependency/code candidate after license/security review.
   - `ADAPT` — useful behind a Vortex-owned adapter/contract.
   - `REFERENCE` — study architecture/algorithms/UX only; do not vendor or depend on it.
   - `REJECT` — unsuitable for the owning Build.
4. Record the decision and evidence before implementation begins.
5. Never blindly vendor a repository. Preserve license/provenance requirements and Vortex authority boundaries.
6. When a candidate becomes architecturally relevant, update the appropriate Guardian/doctrine inventory rather than leaving the decision only in this backlog.

**Do not bulk-audit this file.** The point is to avoid spending time evaluating repositories before their owning Build is reached.

Review states used below:
- `UNREVIEWED`
- `REVIEWING`
- `ADOPT`
- `ADAPT`
- `REFERENCE`
- `REJECT`

All repositories below were supplied by the user. Their presence here is **not** a statement that the repository is safe, maintained, compatible or license-eligible.
