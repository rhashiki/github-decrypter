# GitHub Decrypter — V1 Non-Goals

Status: FROZEN

The following are explicitly outside V1 unless required to correct a security defect, acceptance failure, or contradiction in frozen scope.

- Do not become a domain registrar.
- Do not build a proprietary cloud hosting platform as a requirement for V1.
- Do not build a proprietary database/backend platform as a requirement for V1.
- Do not train or create a foundation AI model from scratch.
- Do not make any paid AI API mandatory.
- Do not make Supabase mandatory.
- Do not make Vercel, Netlify, Cloudflare, Firebase, Appwrite, Convex, or any other single provider mandatory.
- Do not replace Git as project version-control authority.
- Do not use GitHub API as the primary development filesystem when a local workspace is available.
- Do not make the Chrome extension responsible for long-running heavy execution.
- Do not make the PWA/browser tab responsible for job durability.
- Do not promise physically infinite token/context windows; solve the workflow through task decomposition, persistent state, resumability, and context orchestration.
- Do not silently auto-fix code merely because an error is observed in Preview.
- Do not silently deploy to production.
- Do not silently mutate production databases.
- Do not silently change DNS.
- Do not silently push or merge code contrary to the configured approval policy.
- Do not allow plugins, MCP servers, providers, or agents to bypass capability/scope/trust boundaries.
- Do not add automatic cross-repository synchronization with Lovable Decrypter.
- Do not pursue pixel-perfect copying of Lovable branding, assets, or proprietary visual identity.
- Do not make React a requirement for user projects; React is the Studio technology, not the project constraint.
- Do not require internet access for local capabilities that are already installed and inherently local.
- Do not add mobile-native IDE functionality beyond what naturally works through the PWA unless separately planned after V1.
- Do not add collaborative real-time multi-user editing comparable to Google Docs in V1 unless a frozen V1 capability explicitly requires it.
- Do not add a marketplace billing/e-commerce system for third-party plugins in V1.
- Do not add arbitrary new AI agents beyond the frozen agent roles simply because a new specialization seems useful during implementation.
- Do not create sub-builds to absorb newly imagined scope.

New ideas belong to RFC and a future planning window.
