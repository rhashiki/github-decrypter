# Engineering Intelligence & Portable Generation

Status: **Architecture doctrine — Amendment 009**

## Local Model Advisor

Environment Doctor + Model Manager may evolve a local advisor:

```text
hardware facts
+ runtime facts
+ model capabilities
+ benchmark/evidence confidence
+ task requirements
→ candidate filtering
→ fit/speed/quality ranking
→ internal route recommendation
```

A future implementation may reuse permissively licensed `whichllm` components after dependency/security review, or implement the same concepts natively. Normal UX remains Vortex Ars AI.

## Memory lifecycle

```text
observe
→ sanitize/provenance
→ durable Project Memory revision
→ deterministic indexes
→ bounded brief/retrieval
→ typed handoff
→ access/contradiction/dedup signals
→ optional superseding consolidation
```

The zero-LLM path remains useful. Human-readable Markdown/JSON may be exported/mirrored but does not silently replace current canonical storage. LLM consolidation is optional and non-authoritative.

## Engineering work loop

```text
Product Contract
→ inspect affected system
→ architecture/impact
→ concrete plan
→ minimal safe change
→ formatter/static gates
→ behavioral tests
→ review/evidence
→ correction
→ RC Gate
```

Minimal solution ladder: need → existing project → stdlib → native platform → installed dependency → small direct implementation → new abstraction.

## Write-time Quality Gate

Changed files may flow through autoformat, lint/type/security/config checks, structured violations, targeted repair and recheck. Protected check configuration is not an escape hatch.

## Browser Adapter Layer

A verified adapter has actions/extractors, stable refs, auth/session requirements, verification probes and drift signature. OpenCLI is an Apache-2.0 direct-integration candidate after review.

## Embedded Agent Blueprint

Generated apps may include a scoped agent. PageAgent is an MIT candidate for compatible web projects, but never a mandatory Core dependency. Production scaffolding must keep provider secrets out of browser source.

## Portable Component IR

A component IR may capture component tree, props/events, state, bindings, conditions/repetition, slots, styling/tokens, accessibility semantics and source identity. Target emitters produce native framework code. Mitosis is an MIT candidate/reference.

## Database Visual Intelligence

Database Agent emits a normalized schema graph for Code Explorer/Visual Inspector. Credential-minimized user-run introspection is first-class where feasible. ChartDB is AGPL-3.0 and reference-only by default.

## Media Recipe Engine

Media prompts become structured recipes with provenance and expected properties. A case library supports regression across local models. `awesome-gpt-image-2` is MIT and its prompt-engine concepts/templates are candidates where provenance and compatibility are retained.

## Portable Artifact Source

Documents/reports/books/presentations use versionable source suitable for re-rendering. Quarkdown is GPL-3.0 and reference-only by default; its multi-target/live-preview/permission concepts are useful.

## Optional Binary Intelligence

Ghidra may be invoked as an optional separately managed analyzer through Plugin/Code Intelligence boundaries. Prefer headless automation and normalized output. Packaging reviews Ghidra's module-level/mixed license obligations.

## GitHub developer ergonomics

Git Panel/Terminal may borrow MIT gh-dash interaction patterns: keyboard-first navigation, configurable sections, filters, previews, status/check visibility and contextual actions.

## Interaction-shell reference

LobeChat is useful for conversation/knowledge/plugin UX and progressive configuration, but current LobeHub licensing includes commercial derivative restrictions. It is reference-only unless separately licensed.

## Quality methodology sources

Superpowers, Plankton and Ponytail may feed Vortex-native engineering rules/Specialist Profiles: spec/design/plan discipline, systematic debugging, appropriate TDD, write-time deterministic checks, protected quality config and minimal safe solutions. Third-party skills never override Product Contract, Guardian, Tool Runtime, Scope Lock or RC Gate.
